# Foundation integration

Canonical source, methods, exact graph formulas, independent character tables,
and science certificates are materialized here. Their original bytes are bound
by `../data/combined/source-lock.json`.

`upstream-source.tar.gz` contains the **complete** original tracked repository
at the pinned commit, including historical audits, numerical output trees,
manuscript variants and release bundles. The archive is a deterministic
`git archive` plus gzip, and its SHA-256 is recorded in the source lock.
Extract into a separate directory to inspect or reproduce historical routes.
Some links in the unchanged upstream README refer to those archived routes.

The unified project uses the current root README and science status. Original
attribution and license remain intact. Generated Python caches are excluded
from the source snapshot.
