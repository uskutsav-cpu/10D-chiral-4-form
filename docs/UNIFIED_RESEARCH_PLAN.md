# Unified research plan and completion requirements

The project joins the explicit five-form invariant atlas and the chiral
four-form flow classification. Verification is organized around one chain:

1. Import and hash-bind the actual invariant formulas and independent character
   derivation. Preserve the original upstream snapshot and attribution.
2. Recompute rank 81 and generic Lorentz orbit rank 45 independently, then check
   the two tensor engines agree on conventions and all selected graph values.
3. Certify the tensor-to-polynomial map through the chosen finite cutoff using
   bounded exact arithmetic and an injective invariant evaluation set.
4. Independently check nonlinear obstruction ideals, exact tangency, and
   constructive endpoints. Corrupt representative inputs and require rejection.
5. Verify generalized completion using exact homogeneous constant blocks. Keep
   any minimality statement narrower than what the calculation proves.
6. Provide a coherent manuscript, source locks, logs, runnable commands and a
   reviewable Git branch. Validate a clean exported checkout before release.

The chosen finite classification cutoff is twelve, matching both source
projects. This does not redefine an all-orders theorem as a finite result:
full all-orders orbit equality remains an explicitly named open research problem.
A verified finite obstruction can yield an invariant formal cylinder under the
filtration hypothesis, but this does not prove sufficiency in the full formal
space. No unsupported stabilization claim is needed for the combined result.

The full map calculation must finish before the degree-twelve physical identity
is reported as freshly verified. A pending process, modular rank agreement,
a finite holdout, or a copied success label is insufficient.

The source repositories are preserved. Integration changes target a separate
branch of the flow repository; the invariant project is bundled as a pinned
foundation. No merge to the default branch is required to make the work concrete
and reviewable.
