# Targeted prior-work comparison

Checked against the primary arXiv records on November 13, 2026. This is a
focused comparison, not an exhaustive priority determination.

| Source | Existing contribution relevant here | Boundary for this project |
|---|---|---|
| Cederwall, Hutomo, Kuzenko, Lechner and Sorokin, *Some remarks on invariants*, arXiv:2509.14350 | Structure and counting of self-dual-form invariants, including the ten-dimensional problem | Do not present the number 81 or invariant-theory counting as newly discovered here |
| Hutomo, Lechner and Sorokin, *On non-linear chiral 4-form theories in D=10*, arXiv:2509.14351 | Ten-dimensional nonlinear chiral-form theories and the need for structures beyond stress-tensor invariants | The broad failure of stress-only universality is prior work; distinguish explicit orbit ideals and constructive algorithms |
| Elamaran, Ferko and Scarlett, *Machine Learning Invariants of Tensors*, arXiv:2512.23750 | Graph/tensor-network enumeration and data-driven invariant analysis | Graph enumeration itself is not a new contribution; explain exact certification and the ten-dimensional atlas |

The combined work should be judged on its explicit contraction atlas,
independently derived dimensions, bounded tensor-map certificates, nonlinear
orbit equations, constructive signed-control reachability, and carefully scoped
completion results. Each statement still requires theorem-level comparison
with the papers and their references before claiming priority.
